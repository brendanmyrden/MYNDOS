## Project Goal

Building **MYND OS** — a modular personal operating system in the browser. Think apps, not pages: each module is a self-contained environment with its own data, theme, and UI. Long-term direction includes AI integration, personal data tracking, and a unified interface for life/work systems.

## Communication Preferences

- Short answers by default — skip preamble, skip summaries
- Step-by-step when implementing; one step at a time unless told otherwise
- High clarity over high volume
- No filler, no generic best-practice lectures
- If something is ambiguous, ask one focused question before proceeding

---

## Development Style

- **Modular systems**: each feature is a self-contained unit with clear boundaries
- **OS-style architecture**: modules, widgets, themes, and data layers are composable
- **Clean UI/UX**: dark, cyberpunk-adjacent aesthetic; intentional visual language
- **Scalable from day one**: patterns chosen to support many modules, not just the current few
- **No premature abstraction**: build what's needed, refactor when the pattern is clear

---

## Priorities

1. **Speed** — ship working things fast
2. **Execution** — ideas matter less than what gets built
3. **Learning by building** — explanations are welcome when they clarify *why*, not just *what*
